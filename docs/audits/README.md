# Rapports d'audit

Tout audit (revue de bugs, revue d'architecture, etc.) dont le détail doit
survivre au-delà de la session de l'agent qui l'a produit va ici — jamais
dans `worklog.md` ou `download/`, qui sont gitignorés (voir AGENTS.md,
section « Rapports d'audit »).

Convention de nommage : `AAAA-MM-JJ-sujet.md` (ex. `2026-07-26-cto-audit.md`).

Le détail de l'audit du 26/07/2026 (98 bugs identifiés — voir `TODO.md`
« Audit CTO 2026-07-26 ») n'a jamais été commité ici : c'est l'incident qui
a motivé cette règle. Seuls les items individuellement repris dans
`TODO.md` ont survécu ; les ~76 autres (Batch 8/9, Medium/Low) sont
irrécupérables.
