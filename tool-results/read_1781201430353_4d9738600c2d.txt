   310→    <div style="border:1px solid var(--grey-200);border-radius:8px;padding:16px;margin-bottom:16px;">
   311→        <h3 style="margin-bottom:8px;">CU1 — Un agent signale un événement dans le registre RSST</h3>
   312→        <p style="font-size:12px;color:var(--grey-500);margin-bottom:10px;">Profil : Agent • Registre : RSST</p>
   313→        <div style="font-size:13px;line-height:1.8;">
   314→            <strong>Situation :</strong> Jean, agent à l'UR Côte-d'Or, constate que la rampe d'escalier du 2e étage est desserrée et présente un risque de chute.<br><br>
   315→            <strong>Parcours :</strong>
   316→            <ol style="padding-left:20px;">
   317→                <li>Jean se connecte à l'application (automatiquement via Windows Auth en prod)</li>
   318→                <li>Sur l'accueil, il clique sur <strong>« Inscrire un signalement »</strong> sur la carte RSST</li>
   319→                <li>Il remplit le formulaire :
   320→                    <ul style="padding-left:18px;">
   321→                        <li><strong>Objet</strong> : « Rampe d'escalier desserrée - risque de chute »</li>
   322→                        <li><strong>Date de l'événement</strong> : date du jour</li>
   323→                        <li><strong>Lieu</strong> : « Bâtiment principal, 2e étage, escalier B »</li>
   324→                        <li><strong>Description</strong> : détail de la situation observée</li>
   325→                    </ul>
   326→                </li>
   327→                <li>Il valide → le signalement est créé avec le statut <span class="badge badge--nouveau">Nouveau</span> et la référence <code>rsst-25-001</code></li>
   328→                <li>Un e-mail de notification est envoyé aux adresses configurées pour ce site</li>
   329→                <li>Jean peut suivre son signalement dans la liste RSST de son site</li>
   330→            </ol>
   331→        </div>
   332→    </div>
   333→
   334→    <!-- CU2 : RAMI pour un tiers -->
   335→    <div style="border:1px solid var(--grey-200);border-radius:8px;padding:16px;margin-bottom:16px;">
   336→        <h3 style="margin-bottom:8px;">CU2 — Signalement RAMI pour le compte d'un collègue</h3>
   337→        <p style="font-size:12px;color:var(--grey-500);margin-bottom:10px;">Profil : Agent • Registre : RAMI</p>
   338→        <div style="font-size:13px;line-height:1.8;">
   339→            <strong>Situation :</strong> Sophie, agent au Siège, est témoin d'une agression verbale envers son collègue Pierre par un usager. Pierre est trop choqué pour faire le signalement lui-même.<br><br>
   340→            <strong>Parcours :</strong>
   341→            <ol style="padding-left:20px;">
   342→                <li>Sophie clique sur <strong>« Inscrire un signalement »</strong> sur la carte RAMI</li>
   343→                <li>Elle remplit le formulaire et coche <strong>« Pour le compte de »</strong> (champ spécifique RAMI)</li>
   344→                <li>Elle sélectionne <strong>Pierre Dupont</strong> dans la liste des agents comme bénéficiaire du signalement</li>
   345→                <li>Elle décrit les faits de manière objective avec date, heure et lieu</li>
   346→                <li>Le signalement est enregistré — Sophie apparaît comme déclarant, Pierre comme « pour le compte de »</li>
   347→            </ol>
   348→        </div>
   349→    </div>

   353→        <h3 style="margin-bottom:8px;">CU3 — Signalement d'un Danger Grave et Imminent (DGI)</h3>
   354→        <p style="font-size:12px;color:var(--grey-500);margin-bottom:10px;">Profil : Agent • Registre : DGI</p>
   355→        <div style="font-size:13px;line-height:1.8;">
   356→            <strong>Situation :</strong> Marc, agent à l'UR Doubs, découvre une fuite de gaz dans les locaux. La situation nécessite une intervention immédiate.<br><br>
   357→            <strong>Parcours :</strong>
   358→            <ol style="padding-left:20px;">
   359→                <li>Marc clique sur <strong>« Inscrire un signalement »</strong> sur la carte DGI (couleur rouge)</li>
