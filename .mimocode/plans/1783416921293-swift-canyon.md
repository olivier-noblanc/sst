## 4. Erreur SQL FOREIGN KEY constraint failed

**Objectif** : Corriger l'erreur `SQLSTATE[23000]: Integrity constraint violation: 19 FOREIGN KEY constraint failed`.

### Hypothèse
L'erreur pourrait survenir si un site_id invalide est soumis, ou si des contraintes FK sont violées lors de la création/réponse. L'utilisateur suggère des tests Playwright.

### Action
- Ajouter des vérifications de FK dans les handlers (vérifier que `site_id` existe dans la table `sites` avant INSERT)
- Les handlers `report_create_handler.php` et `report_respond_handler.php` valident déjà `site_id` — vérifier qu'aucun cas n'échappe
- Tester les flux complets avec Playwright après implémentation

## 13. Bug : Changement de rôle KO

**Objectif** : Corriger le fait que le rôle ne change pas quand un superviseur modifie le rôle d'un utilisateur.

### Investigation
Le handler `user_edit_handler.php` semble correct :
- `validateUserFields()` valide le rôle
- `updateUser()` met à jour le rôle en DB
- `refreshCurrentUser()` recharge la session

### Hypothèse probable

### Fichiers à investiguer/corriger
- `src/validation_user.php` — vérifier la logique site_id validation
- `handlers/user_edit_handler.php` — ajouter un message d'erreur clair si la validation échoue
