   313→    <!-- CU1 : Agent signale -->
   314→    <div class="help-profile-card card--spaced">
   315→        <h3>CU1 — Un agent signale un événement dans le registre RSST</h3>
   316→        <p class="text-small text-muted help-case-label">Profil : Agent &bull; Registre : RSST</p>
   317→        <div class="help-feature-list help-case-body">
   318→            <strong>Situation :</strong> Jean, agent à l'UR Côte-d'Or, constate que la rampe d'escalier du 2e étage est desserrée et présente un risque de chute.<br><br>
   319→            <strong>Parcours :</strong>
   320→            <ol>
   321→                <li>Jean se connecte à l'application (automatiquement via Windows Auth en prod)</li>
   322→                <li>Sur l'accueil, il clique sur <strong>« Inscrire un signalement »</strong> sur la carte RSST</li>
   323→                <li>Il remplit le formulaire :
   324→                    <ul class="help-feature-list">
   325→                        <li><strong>Objet</strong> : « Rampe d'escalier desserrée - risque de chute »</li>
   326→                        <li><strong>Date de l'événement</strong> : date du jour</li>
   327→                        <li><strong>Lieu</strong> : « Bâtiment principal, 2e étage, escalier B »</li>
   328→                        <li><strong>Description</strong> : détail de la situation observée</li>
   329→                    </ul>
   330→                </li>
   331→                <li>Il valide &rarr; le signalement est créé avec le statut <span class="badge badge--nouveau">Nouveau</span> et la référence <code>rsst-25-001</code></li>
   332→                <li>Un e-mail de notification est envoyé aux adresses configurées pour ce site</li>
   333→                <li>Jean peut suivre son signalement dans la liste RSST de son site</li>
   334→            </ol>
   335→        </div>
   336→    </div>

   339→    <div class="help-profile-card card--spaced">
   340→        <h3>CU2 — Signalement RAMI pour le compte d'un collègue</h3>
   341→        <p class="text-small text-muted help-case-label">Profil : Agent &bull; Registre : RAMI</p>
   342→        <div class="help-feature-list help-case-body">
   343→            <strong>Situation :</strong> Sophie, agent au Siège, est témoin d'une agression verbale envers son collègue Pierre par un usager. Pierre est trop choqué pour faire le signalement lui-même.<br><br>
   344→            <strong>Parcours :</strong>
   345→            <ol>
   346→                <li>Sophie clique sur <strong>« Inscrire un signalement »</strong> sur la carte RAMI</li>
   347→                <li>Elle remplit le formulaire et coche <strong>« Pour le compte de »</strong> (champ spécifique RAMI)</li>
   348→                <li>Elle sélectionne <strong>Pierre Dupont</strong> dans la liste des agents comme bénéficiaire du signalement</li>
   349→                <li>Elle décrit les faits de manière objective avec date, heure et lieu</li>
   350→                <li>Le signalement est enregistré — Sophie apparaît comme déclarant, Pierre comme « pour le compte de »</li>

   359→        <div class="help-feature-list help-case-body">

   376→        <div class="help-feature-list help-case-body">
